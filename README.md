# 🍔 CraveBite — Pre-Order Food System

**CraveBite** is an MVP (Minimum Viable Product) for a food pre-ordering system that allows customers to browse available food items, place orders in advance, and manage their orders through a simple web interface.

The project is designed to demonstrate the core functionality of a food ordering platform while keeping the architecture simple and easy to extend.

## 🛠️ Tech Stack

* **HTML** — Structure and markup
* **CSS** — Styling and responsive UI
* **JavaScript** — Client-side interactions
* **PHP** — Backend logic and server-side processing
* **MySQL** — Database and data management

## ✨ MVP Features

* Browse available food items
* View food details and prices
* Add food items to an order
* Place pre-orders
* Store and manage orders
* Basic order management
* Database-backed food and order information
* Simple and user-friendly interface



> The project structure may change as new features are added.




## 🗄️ Database

CraveBite uses **MySQL** to store application data such as:

* Food items
* Categories
* Customers
* Orders
* Order details
* Order status

The database structure may evolve as the project moves beyond the MVP stage.

## 🎯 Project Goal

The main goal of CraveBite is to build a functional foundation for a **pre-order food platform** and provide an MVP that can be expanded with more advanced features over time.

## 📌 Project Status

**Status: MVP / In Development**

CraveBite is currently an MVP project. Some features may be incomplete or subject to change as development continues.
